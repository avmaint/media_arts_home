Reading the fixture sheet — colours, layers and chips

Every colour the grandMA3 fixture sheet throws at you, decoded: what the text colour means, what the background means, what the extra layers look like, and what those little rectangles above a cell are telling you. None of this is fixture-specific — it describes the console, so it reads the same whatever you have patched.

01

Reading the value cells

Two questions answer almost every cell. What colour is the text? — that's where the value comes from. What colour is the background? — that's whether it's active, and what the console is doing with it right now.

The short version

White on red is yours and will store. Red text on grey is yours but deactivated and won't. Everything else on a grey background is playback telling you where the level came from.

Why a value won't store

If a change refuses to end up in your cue, it's almost always deactivated — red text on grey, not white on red. Re-select the fixtures and press Please Please to reactivate, then store.

02

The other layers

Beyond the absolute value, an attribute can carry extra layers — relative offsets, individual timing, phasers. They all follow one rule: white text on the layer's colour = it's in your programmer; the layer's colour as text on grey = it's coming from the selected cue.

-5
MauveRelative value (an offset rather than an absolute).
2s
GreenIndividual fade time on that attribute.
1s
OrangeIndividual delay time on that attribute.
~
PurplePhaser value — every phaser layer shares this one colour.
3
ShamrockGridPos value (MAtricks grid position). Deactivated shows as shamrock text on grey.
Dimmed = other part

A darkened version of any programmer colour means the data lives in a programmer part other than the one the sheet is currently showing — not a different meaning, just a different part.

03

The little rectangles (indicator chips)

Those small colour bars sitting at the top of the fixture name and the value cells are indicators, not values. A bar above the name means active programmer info for that fixture; a bar above only a value means it's outputting from a sequence. Their colour tells you which kind of data is present.

RedActive absolute programmer value.
MauveActive relative programmer value.
GreenIndividual fade time.
OrangeIndividual delay time.
PurplePhaser value.
Bright cyanAbsolute value pulled from a preset.
Dark cyanRelative value pulled from a preset.
BlueParked attribute.
White · left sideLayer info in the programmer that won't store as active.
White · right sideComing from the DMX Tester — not stored with active values.

Two more you'll bump into

Small yellow (while editing a preset)This attribute holds the global value for all fixtures of that type in the preset.
Green square · top-right of a cellAn active recipe value is driving that attribute.
Above the ID / type

Chips sitting above the IDType (not the value) flag a group master on that fixture: light pink = positive/negative/scaling master, lavender = additive master, blue = Master React set to None.
