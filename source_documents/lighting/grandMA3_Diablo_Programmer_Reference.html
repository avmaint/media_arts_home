01

The loop every parameter follows

Whatever you're changing — dimmer or a framing blade — the motion is the same four beats. Learn it once and every feature group below is just a variation on it.

01

Select

Pick the fixtures. Yellow ID text = selected. Nothing happens to anything you haven't selected.

02

Choose a group

Tap a feature group on the encoder bar. The four encoders remap to that group's attributes.

03

Set the value

Turn an encoder, or push it to open the Edit overlay (named Channel Sets + typed values), or type it on the command line.

04

Keep or drop

Active values (white-on-red) get stored. Clear steps them back out. Store to a preset to reuse.

Where a control actually lives

The encoder bar shows up to five dual encoders at a time. A feature group with more than that spreads across several encoder pages, one per feature — the Encoder Page button to the left of the encoders names the current feature and shows how many pages the group has. Tap it to cycle, or tap and swipe for the list. Wherever a control on this fixture is not on the first page of its group, this document flags it later page.

Selecting the Diablo(s)

Fixture 21 Thru 24 — range of Diablos by Fixture ID Group 10 — if you've stored them as a group Please Please — pushes all current values into the programmer & activates them

On the command line, Fixture is the default keyword, so a bare number selects by Fixture ID. Every value you set below lands in the programmer for the current selection only.

02

Feature group by feature group

Each card is one bank on the encoder bar. Tapping the group name pages the encoders onto its attributes; tap again / use the feature buttons to reach the second and third page when a group has more than four. Attribute names in the examples come from the fixture library — push an encoder or open the DMX sheet to confirm the exact spelling on your Diablo profile.

Dimmer

Preset Type 1

Intensity. The one group with dedicated hardkeys, so you rarely need the encoder here.

Fast paths
  • At 50 → 50%  ·  Full → 100%  ·  Off → knock intensity out
  • At At → the "Normal" default level  ·  level wheel for a live grab
DIABLO · CH 7–8 Single 16-bit intensity attribute (Dimmer, coarse ch7 / fine ch8). Descending dimmer values show green text when they come from a cue — see §04.

Position

Preset Type 2

Pan and tilt. Encoders 1 & 2 once the group is selected.

Command line
Attribute "Pan" At 0 Attribute "Tilt" At 45 At Preset 2.3 — recall stored Position preset 3
Spreading across the rig
  • Select several, then use MAtricks / fan mode to spread pan & tilt into a line, fan, or circle instead of one flat value.
DIABLO · CH 1–5 16-bit Pan (ch1/2) and Tilt (ch3/4). Ch5 is a Pan/Tilt movement-speed attribute (PanTiltSpeed / PositionMSpeed) — leave it at default unless you want the head itself to govern crossfade speed. A green fixture name = MAtricks-inverted control; light-green = an "edge" fixture holding symmetry.

Gobo

Preset Type 3

Wheel slot selection, gobo rotation, and the animation wheel. This group spreads across two encoder tiles — the gobo wheel (2 knobs) and the animation wheel (Anim1).

Pushing an encoder = the Edit overlay
  • Push a gobo encoder and you get the Edit 'Gobo1' window — that is the calculator, just titled by attribute. It opens on the Specials tab (Release / Off / Full / Highlight), which is why you see a keypad, not gobo names.
  • Tap Channel Sets in the middle column to flip the panel to the named slots: Dot Line 11, Starfield, Nested Triangle, Tourbillon, Vortex, B&W Target, Nested Rings Yellow. Tap one, then Please.
The two gobo-wheel encoders
  • Encoder 1 — G1 selects a static gobo (steps through the channel sets); Wheel spins the whole wheel so every gobo cycles past the beam. These are the two channel functions shown as tabs Gobo1 1 and Gobo1WheelSpin 2 in the overlay.
  • Encoder 2 — G1 <> indexes the selected gobo to a fixed angle; Rotat spins that one gobo on its own axis (Gobo1Pos, ch29/30, 16-bit).
  • The trap: Wheel cycles all gobos through the gate; Rotat spins a single gobo in place. Two different looks that both read as "spinning." All Channel Sets (top-right of the overlay) lists both functions at once.
Reading the [0.0000 .. 8.0000] value
  • That range is the attribute's own logical value — not DMX 0–255 and not a gobo number. Each named channel set sits at a point in it, spaced roughly 0.5 apart, so the encoder detents slot-to-slot.
  • Order matches the Ayrton ch28 layout: the seven solid gobos first, then the same seven as shakes (which is why the patterns repeat from ~3.5 with a shake added), then whole-wheel spin at the top.
  • Correction to typed entry: 1 Please sets the value to 1.0, landing on whatever channel set sits there — not "gobo 1," and it can land between slots. Use the named Channel Sets for a predictable hit, or spin to the gobo and reuse the value it settles on.
Animation wheel — Anim1 (ch31)
  • One encoder, but four channel functions, because Ayrton rides the whole effect on a single DMX channel: AnimationWheelSelect 1 = open / out of beam · AnimationWheel1PosRotate 2 = forward spin (value = speed) · AnimationWheelSelect 3 = inserted, no rotation · AnimationWheel1PosRotate 4 = backward spin.
  • They're mutually exclusive — you're only ever in one. Sweeping the encoder runs open → spin-fwd → stop → spin-back. Use a PosRotate for movement, Select 3 for a static texture, Select 1 to pull it out.
DIABLO · CH 28–31 One rotating gobo wheel (ch28 select / ch29–30 rotate) plus the animation wheel (ch31). No separate static gobo wheel in this mode.

Color

Preset Type 4

The richest group on this fixture. The encoder bank runs three pages — CMY, then wheel + warm-shift, then the LED-engine effects.

Page 1CMY mix
  • Cyan Magenta Yellow — continuous 16-bit subtractive mix (ch20–25; GDTF names ColorSub_C/M/Y). The Colour Picker and swatch/gel pools drive these too, and are cleaner for mixing.
Page 2Wheel & warm-shift
  • C1 = Color1, the fixed colour wheel (ch18/19): Open, CTB ¼, Magenta, Congo Blue, Green, Orange, Blue, Red, plus colour-indexing and bidirectional rainbow. Push → Channel Sets for the names. It stacks in front of the CMY mix.
  • CTO later page = continuous colour-temperature-orange (ch26/27). A smooth warm-shift fader — 0 untouched, full = max warm. The clean way to warm white or CMY without touching the mix.
Page 3LED engine effects
  • A linked trio driving colour macros inside the fixture's LED engine — the head generates the look; the console just picks and paces it.
  • LEDEngineEffects = the selector (slotted; Off/None, then each built-in engine macro). Nothing else acts until this is on an effect.
  • LEDEngineEffectRate = overall speed of the selected effect.
  • LEDEngineEffectStepTime = the per-step transition — snap vs. crossfade between steps. Rate = how often it steps; StepTime = how each step looks.
Attribute "Cyan" At 100 — full cyan (ch20/21, 16-bit) Attribute "CTO" At 50 — warm the beam (ch26/27)
Verify on your profile

The three LED-engine attributes are not on the V203 DMX chart — its only engine is the generic Internal Programs range on control ch56. So they're either a newer library revision exposing that engine under Colour, or virtual attributes. Push each one: a real named Channel Set list = live in 56-ch mode; a bare/greyed list = present but inert here.

DIABLO · CH 18–27 Colour wheel (ch18/19) + CMY (ch20–25) + CTO (ch26/27), all continuous 16-bit except the slotted wheel.

Beam

Preset Type 5

Everything that shapes the quality of the beam short of size and edge: shutter/strobe, prism, frost, iris. Runs two encoder pages — the attributes, then an effect selector.

Page 1The Diablo's beam attributes
  • Shutter1 (ch6) — closed, open, strobe (slow→fast), pulse sequences, random strobe, all on one attribute. Push for the named ranges.
  • Prism1 (ch34) — single 5-facet circular prism (open below 128); Prism1Pos (ch35/36, 16-bit) indexes or spins it.
  • Frost1 (ch37) — linear 0–100% frost.
  • Iris (ch32/33, 16-bit) — max→min diameter, plus pulse-open / pulse-close ranges up top.
Page 2Effect selector
  • Effect = the Beam group's macro selector (slotted; Off/None, then each fixture-internal beam macro). Same family as Colour's LEDEngineEffects, scoped to Beam — it fires packaged prism/shutter engine looks rather than you dialling each attribute by hand.
  • Push it and read the Channel Sets. If a live effect exposes its own pacing, expect a paired EffectRate / EffectStepTime on the same or an adjacent page.
Verify on your profile

The generic Effect selector is not on the V203 chart — its only built-in engine is Internal Programs on control ch56. Treat this like the LED-engine trio: a real named Channel Set list = live in 56-ch mode; a bare/greyed list = present in the profile but inert here.

DIABLO · CH 6, 32–37 One prism, one frost, one iris. Iris usually sits in Beam here, but if your encoders show it under Focus that's just library grouping — same attribute. The animation wheel is not here; it's a Gobo feature (ch31).

Focus

Preset Type 6

Zoom, focus, and the Diablo's distance-based autofocus.

Attribute "Zoom" At 20 — narrow (ch12/13, 16-bit) Attribute "Focus" At 55 — crisp the gobo edge (ch14/15)
DIABLO · CH 12–17 16-bit Zoom and Focus, both continuous. Ch16/17 is Auto Focus — a stepped distance attribute (Off, 5 m, 7.5 m, 10 m, 15 m). It appears as its own attribute (often AutoFocus / a Focus-distance control); set it to a throw band and the head holds sharpness for you. Store a Focus preset per throw distance so re-sharpening a gobo is one recall.

Shapers

Preset Type 8

The miniaturised 4-blade framing system — each blade drives from two ends, so it can insert and tilt. Plus rotation of the whole module.

Exact attribute layout (16-bit each)
  • Four blades, two ends apiece: Blade1A/Blade1B … Blade4A/Blade4B (ch38–53). Each end runs open→close; driving A and B differently angles that blade.
  • ShaperRot / All-Blade Rotation (ch54/55) spins the entire frame module ±45°.
  • Eight blade attributes + rotation = well past four encoders, so expect to page the Shapers bank two or three times.
Attribute "Blade1A" At 40 — insert one end of blade 1 Attribute "Blade1B" At 15 — less on the other end = an angled cut Attribute "ShaperRot" At 50 — rotate the whole frame (±45°)
DIABLO · CH 38–55 Confirm the exact attribute spelling (some libraries use Blade1A/Blade1B, others Frame-prefixed) by pushing the encoder — the calculator title shows the live attribute name.
03

Programmer housekeeping

Two mechanics that save you from mystery states while building looks.

Activate vs. deactivate

Only active values store by default. A value can sit in the programmer inactive — present, affecting output, but skipped by Store/Update. Please Please activates everything for the selection; Off then a tap on a value knocks that one out; Off + a feature-group bank button releases the whole group.

The three states of Clear

Clear ×1 — deselect fixtures (values stay, still active) Clear ×2 — values stay but go deactivated (a store now = empty) Clear ×3 — programmer emptied, values released

Hold Clear for a second to jump straight to a full release.

Why a value won't store

If a change refuses to end up in your cue, it's almost always deactivated (red text on grey, not white-on-red). Re-select and press Please Please, then store.

04

Reading the sheet

Cell colours, layer colours and the little indicator rectangles are the console talking, not the fixture — so they live in one shared document rather than being repeated here.

Shared legend

grandMA3 — Reading the fixture sheet →

Every text / background combination in the value cells, the layer colours (relative, individual fade and delay, phaser, GridPos), and what each indicator chip means.
The short version

White on red is yours and will store. Red text on grey is yours but deactivated and won't. Everything else on a grey background is playback telling you where the level came from. A black cell means the attribute doesn't exist on this fixture — the Diablo has no white emitter, for instance.
